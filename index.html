03 — How I work

From raw tables to running systems.

Analysis that stops at a slide deck leaves the operational problem unsolved; software that ignores grain and validation invents confidence.

01

Question

Start from the business decision, not the chart. Clarify users and non-goals.

02

Data

Profile source tables, document grain before joins, keep exclusions auditable.

03

Insight

Define KPIs from source fields and cross-check findings in more than one tool.

04

Decision

Recommend actions only where the evidence is strong enough to act.

05

System

Build the product: entities and constraints first, then UI, tests and deployment.

Analytical practice

  • Start from the business decision, not the chart.
  • Profile source tables and document grain before joins.
  • Clean and validate with explicit rules; keep exclusions auditable.
  • Define KPIs from source fields, not preferred narratives.
  • Cross-check findings in more than one tool when the stakes are high.

Data → software

Restaurant financial analysis became ControlDeck NG, a product UI over the same control gaps. Booking demand became Bibiunique: an availability API, a unique slot constraint and admin approval instead of inbox chaos. A church’s Sunday logistics became a role-based platform with a realtime projector display.
