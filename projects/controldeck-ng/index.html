ControlDeck NG — Executive BI Dashboard (React & TypeScript)

Full-stack / BI UI · Vite · React 19 · TypeScript · Recharts

A proof-of-concept executive dashboard for Nigerian restaurant, bar and club owners, built with Vite, React 19 and TypeScript. It turns the findings of a restaurant financial analysis into a product surface: KPIs, reconciliation exceptions and alerts a CEO can act on.

Live demoGitHub repository
StackVite · React 19 · TypeScript · Tailwind CSS v4 · Recharts · React Router · Lucide
HostingGitHub Pages (static build)
DataMock operational data shaped by real analysis findings
StatusProof of concept, not production software

Honest scope: ControlDeck NG uses mock data and is not connected to a live bank or POS system. Its AI CEO Assistant returns demo responses grounded in sample metrics. Per the repository README, the product idea, business framing and analytics are Emmanuel’s; the UI implementation was developed with AI coding assistance under his direction.

What it demonstrates

An intelligence and control layer above hospitality operations: POS, payments, inventory and expenses feed a central view, reconciliation exceptions are surfaced, and the CEO sees a dashboard plus Q&A. Exception language is deliberate: “Exception requiring management review”, never an accusation of fraud.

Screens

  1. CEO Home: KPIs, alerts, revenue trend, branch and unit cards.
  2. Financial Control Centre: payee and reference gaps, reconciliation status, exception values.
  3. Sales Intelligence: Restaurant, Bar, Bakery, Club/Lounge, Delivery, Campus, Other.
  4. Cost & Profitability: cost lines, budget vs actual, data-quality warnings.
  5. Inventory: stock, wastage, expected vs actual consumption.
  6. Purchasing: suppliers, price changes, recommended buys.
  7. AI CEO Assistant: natural-language Q&A over demo metrics.
  8. Executive Alerts: Critical / Warning / Normal.

Code structure

The source follows a page-per-screen layout: src/pages/ holds one component per screen (for example CeoHome.tsx, FinancialControl.tsx, AiAssistant.tsx), src/layout/AppShell.tsx provides navigation, src/data/mockData.ts holds the grounded mock data, and src/utils/format.ts handles naira formatting.
