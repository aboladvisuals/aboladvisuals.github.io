Restaurant Financial Intelligence & CEO Dashboard

Data & BI · Python · pandas · SQL · Power BI

A decision-focused financial analysis of a multi-unit restaurant business: revenue, payments, profitability, costs, financial controls and data quality, delivered as a Python pipeline and a Power BI CEO dashboard. The headline finding was a control problem, not a profit number.

GitHub repositoryFollow-on product: ControlDeck NG
ToolsPython · pandas · SQL · Excel · Power Query · Power BI

DeliverablePower BI CEO dashboard + Excel outputs + management action plan

Approach

The repository is organised as a reproducible pipeline in scripts/, numbered in run order:

01_data_audit → 02_build_pnl → 03_build_monthly_pnl → 04_monthly_performance
→ 05_expense_break → 06_payment_vs_pnl → 07_payment_categories → 08_payment_trends
→ 09_revenue_analysis → 10_monthly_revenue_by_unit → 11_profitability_analysis
→ 12_cost_analysis → 13_financial_controls → 14_management_action_plan
→ 15_ceo_executive_summary → 16_build_dashboard_data

Each step writes an Excel or CSV output to outputs/ (for example financial_controls_analysis.xlsx and management_action_plan.xlsx), and the final step builds the data layer used by the Power BI dashboard.

Financial control findings

  • 19,146 payments without a payee.
  • 33,605 receipts without a reference, and 24,159 without a description.
  • About ₦5.74m in positive receivables.
  • A large “Other / Unclassified” payment category, which signals a classification weakness.

Control weaknesses are reported as exceptions for management review. They are not evidence of fraud, and the analysis does not claim they are.

The critical accounting issue

Recorded expenses collapse from April 2026 onward, from about ₦58.5m in March 2026 to about ₦2.1m in April and under ₦1m in each later month. That makes profit margins from April 2026 look unusually high. The recommendation was that reported profitability from that point should not be relied on until expense records are reconciled.

CEO action priorities

  1. Reconcile financial records from April 2026 onward.
  2. Restore complete and consistent expense recording.
  3. Make payee, receipt reference and transaction description mandatory where appropriate.
  4. Reclassify major “Other / Unclassified” payments.
  5. Introduce monthly bank reconciliation.
  6. Strengthen purchasing and stock controls around food and beverage spend.

Limits

  • Control weaknesses (missing payees, references and descriptions) are reported as exceptions for review, not as evidence of fraud.
  • Profitability from April 2026 onward is flagged as unreliable until expense records are reconciled, so no profit conclusion is drawn for that period.
  • The business is not named, and this page does not publish source records.

What this project demonstrates

  • Python data pipeline: 16 ordered pandas scripts from data audit to a dashboard data layer, each writing an inspectable output.
  • Financial and control analysis: revenue mix, payment categories, profitability and data-quality checks.
  • Power BI executive reporting: CEO Overview, Revenue & Cost and Financial Controls pages.
  • Judgement: identifying when a headline number (profit) should not be trusted, and saying so.

From analysis to product

The same findings later shaped the mock data and screens of ControlDeck NG, a React proof of concept for an executive control dashboard.
